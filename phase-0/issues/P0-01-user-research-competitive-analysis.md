- **Assignee:** PM
- **Participants:** FE, Mobile (support interviews + hand UX findings to PM)
- **Priority:** High
- **Status:** 🟢 Done
- **Timebox:** Tue 18/08 → Wed 19/08 — must finish by EOD Wed so PM can write vision Thu
- **Depends on:** —

## Goal

By EOD Wednesday, PM has a clear evidence base of: who the users are, what hurts, why, and what existing solutions exist in the VN rental market. This feeds everything downstream.

## Context

We have 1 week. This issue is the foundation — it cannot be skimped, but it must be time-boxed. Interviews will be short (20 min each, remote if needed). Market analysis has a seed (`market-analysis.md`) that needs extending to long-term rental.
May be we can interview with GPT, Gemini to reach more users, but we need to validate the results with real users.

## Tasks

### D1 (Tue 18/08) — gather evidence
- [ ] Conduct ≥2 landlord interviews (20 min each): current workflow (contract, utility close, invoicing, payment), pain points, what they'd switch for.
- [ ] Conduct ≥2 tenant interviews (20 min each): room search, payment, issue reporting, roommate search pain.
- [ ] Log interview notes in a raw appendix (quotes, not paraphrase).
- [ ] Re-read seed `market-analysis.md`; list 3–4 more competitors for long-term rental (Mona House, KiotViet, iNest, Phòng Trọ 123, NhaTroTot, Chợ Tốt, any roommate apps).

### D2 (Wed 19/08) — synthesize & deliver
- [ ] Extract pain points from interviews: list top 5, ranked by frequency × severity, each with a root cause (1-sentence why).
- [ ] Write user needs as user stories: "As a <persona>, I want <X>, so that <Y>." ≥5 per persona.
- [ ] Draft 2–3 personas: demographics, goals, frustrations, tech comfort, device, rental context.
- [ ] Extend `market-analysis.md`: comparison table (product, price, target, strengths, weaknesses, source), gap analysis (what's underserved → our wedge).
- [ ] Hand everything to P0-03 (PM writes vision) and P0-06 (use cases).

## Deliverables

- `pm/phase-0/discovery/user-research.md` — personas, pain points ranked, needs, interview appendix.
- Updated `pm/phase-0/market-analysis.md` — comparison table + gap analysis.

## Definition of Done

- [ ] ≥4 interviews with notes stored.
- [ ] Top 5 pain points ranked + root causes.
- [ ] 2–3 personas drafted.
- [ ] Market comparison table ≥6 products.
- [ ] PM confirms synthesis is ready for P0-03/P0-06.
